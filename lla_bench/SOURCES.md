# Sources

- The evaluator, task definitions, scoring/generation helpers, RULER and dataset patches, long evaluation planner, paper summary column/average rules (from unused/parse_lmeval_table.py), download tools, and LogKV reference cache allocator come from [HourunLi/LogKV at a126a1b](https://github.com/HourunLi/LogKV/tree/a126a1b3a11262a5dea85c0416b57753a44e9c6f). The private imports, native model/cache adapter, memory fields and launcher are local changes. The reference repository license is included in [LICENSE.md](LICENSE.md). Task-specific notices are preserved beside their definitions.
- The native PyTorch inference implementation follows the weak base-two scalar-gated hierarchy and HAttention Mamba-2 block in [HanGuo97/log-linear-attention at 7f86441](https://github.com/HanGuo97/log-linear-attention/tree/7f8644159c1406fae1ad863829a5b3a4fbf63022/hattention). The tiled products and streaming binary carry are implemented here. Flame pins FLA at [e5c18bf](https://github.com/fla-org/flash-linear-attention/tree/e5c18bf633bb093a38ad915c2cfe3979425ab27c), the reference for gated RMSNorm and SwiGLU dimensions.
- The downloader selects the [published mamba-2 subfolder at 29374fe](https://huggingface.co/hanguo/log-linear-attention/tree/29374fef386e0b8dcce9bfbd14cbcee8334954a1/mamba-2), including its LICENSE and tokenizer. The 3,301,893,488-byte model.safetensors has SHA-256 b53e4e85b6cfe2d55824940625e2e30fb259339c4b1c786bf0c38a9661d1ac4c.
- The 8B training data reader follows the 32K ProLong cache key, token packing, field selection and shuffling in [niahLogKV at 8297f4e](https://github.com/HourunLi/LogKV/tree/8297f4e6237dc0683c1d2f79c7a63424932bf17c) (`data.py`, `demo.py` and `exp/qwen8b-32k`, Apache-2.0, see LICENSE.md). Local changes slice 4K teacher windows from the same packed blocks, prepare optional private caches, and fail on malformed inputs. Qwen backbone transfer, distillation, training and export are local implementations.
